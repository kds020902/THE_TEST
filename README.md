# THE_TEST · 과목별 시험 연습 제작 키트

강의 자료와 시험 범위를 바탕으로 **객관식·단답형·서술형 학습 사이트를 제작하기 위한 공통 프롬프트와 설정 양식**입니다. 컴퓨터 비전 학습 사이트에서 사용한 학습 흐름을 다른 과목에도 적용할 수 있도록 정리했습니다.

현재 저장소에는 제작 문서가 들어 있습니다. 실행 가능한 웹 앱과 배포 환경은 새 과목의 자료를 받아 구현하는 단계에서 추가합니다. 이 저장소를 복제하는 것만으로 사이트가 실행되거나 여러 과목을 자동 관리하지는 않습니다.

## 바로 사용하기

1. [과목 설정 양식](prompts/02_과목_설정_양식.txt)을 복사해 **과목명, 실제 강의 자료, 시험 범위**를 채웁니다.
2. Codex에서 이 저장소를 열거나, 새 대화에 [제작 프롬프트](prompts/01_범용_제작_프롬프트.txt), 채운 양식, [출제 품질 기준](prompts/03_출제_품질_기준.txt), 강의 자료를 첨부합니다.
3. [빠른 시작 요청문](prompts/05_빠른시작_요청문.txt)의 빈칸을 채워 요청합니다.

저장소를 연 상태에서는 다음처럼 시작할 수 있습니다.

> prompts/01_범용_제작_프롬프트.txt와 prompts/03_출제_품질_기준.txt를 읽고, 첨부한 과목 설정과 강의 자료로 학습 사이트를 만들어줘. 자료의 소단원 순서를 지키고 연습·모의시험·새 문제 생성·오답 복습·풀이 저장을 구현해줘. 구현과 검증 후 사용할 수 있는 링크를 알려줘.

실제 자료와 시험 범위를 함께 제공해야 합니다. 문제 수, 제외 내용, 개념·계산·사례·코드 중 평가 대상을 지정하면 과목에 맞게 제작할 수 있습니다. 개인 템플릿 설치는 필수가 아닙니다.

## 제작할 사이트의 공통 기능

- 단원·소단원·문제 유형별 연습과 지정된 구성의 모의시험
- 객관식 보기별 해설, 단답형 인정 표현, 서술형 모범답안과 평가 요소
- 쉬운 말과 예시로 설명하는 **빠르게 이해하기**
- 새 문제 만들기, 생성 이력에 따른 중복 감소와 조합 소진 안내
- 오답·복습 목록, 사용자별 답안 및 진행 저장
- 자료의 단원 순서, 그림·표·수식과 출처 유지

위 항목은 구현 요구사항입니다. 과목마다 내용·정답·그림·채점 규칙·생성 규칙을 실제 자료에 맞게 다시 만듭니다. 단원 수나 문항 수를 원래 과목의 값으로 고정하지 않습니다.

## 생성과 평가 방식

기본 생성 방식은 **검토된 개념과 조건을 조합하는 유한한 규칙 기반 생성**입니다. 보기 순서만 바꾼 문제를 새로운 내용으로 세지 않습니다. AI 자유 생성은 별도 선택이며 실제 모델 연결과 근거 검증이 필요합니다.

서술형의 기본 평가는 모범답안과 핵심 평가 요소를 이용한 **자기 점검**입니다. 실제 교사의 채점이나 AI 자동 채점과 구분합니다. 숫자·수식·코드를 다루는 과목에서는 부호·단위·허용 오차 등 의미 있는 차이를 채점 규칙에 반영합니다.

## 작업 범위 선택

- **새 과목 사이트:** 새 자료와 별도 저장 공간으로 제작합니다. 기본 접근 범위는 비공개입니다.
- **기존 사이트 수정:** 수정할 사이트 또는 프로젝트를 정확히 지정합니다.
- **여러 과목 통합:** 과목 전환과 과목별 출제 데이터·학습 기록 분리를 별도로 구현합니다.

강의 자료 접근용 비밀번호, API 키, 개인 풀이 기록은 저장소에 넣지 않습니다. 개인 템플릿의 원본 앱 소스와 운영 사이트 데이터는 이 제작 문서 패키지에 포함하지 않습니다.
