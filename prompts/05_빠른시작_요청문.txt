THE_TEST 빠른 시작 요청문

아래 요청문을 복사하고 빈칸을 채워 강의 자료와 함께 전달하세요.
이 저장소를 읽을 수 없는 대화에서는 01_범용_제작_프롬프트.txt,
02_과목_설정_양식.txt, 03_출제_품질_기준.txt도 첨부하세요.

────────────────────────────────
요청문
────────────────────────────────

THE_TEST 저장소의 prompts/01_범용_제작_프롬프트.txt와
prompts/03_출제_품질_기준.txt를 읽고, 아래 설정과 첨부한 강의 자료로
과목별 학습 사이트를 만들어줘. 해당 파일을 첨부했다면 첨부본을 사용해줘.

과목명: [입력]
시험 범위: [단원·소단원·페이지 입력]
평가 대상: [개념 / 계산 / 사례 / 코드]
문제 구성: 객관식 [ ]개 / 단답형 [ ]개 / 서술형 [ ]개
제외 내용: [입력 또는 없음]
강의 자료: [첨부 파일 또는 접근 가능한 링크]
기존 정리본: [파일·링크 또는 없음]

단원별 연습, 모의시험, 새 문제 생성, 오답 복습, 해설과 ‘빠르게 이해하기’, 풀이 저장을 포함해줘.
자료의 단원·소단원 순서를 지키고 새 과목의 출처와 채점 규칙을 사용해줘.
새 문제 생성은 기본적으로 검토된 개념을 조합하는 방식으로 해줘.
서술형은 모범답안과 핵심 평가 요소로 자기 점검하도록 해줘.
새 과목용 비공개 사이트를 만들고 구현·검증·게시까지 완료해줘.

────────────────────────────────
사용 안내
────────────────────────────────

- 실제 자료와 시험 범위를 함께 제공해야 과목에 맞는 문항을 만들 수 있습니다.
- 더 자세한 조건은 02_과목_설정_양식.txt에 적으세요.
- 기존 사이트 수정 또는 여러 과목 통합이 목적이면 마지막 요청 문장을 그에 맞게 바꾸세요.
- 개인 템플릿을 설치한 환경에서는 요청문 앞에 $artifact-template-study-lab을 붙일 수 있습니다.
  해당 템플릿과 원본 앱 소스는 이 저장소에 포함되어 있지 않으며, 개인 템플릿 없이도 문서로 요청할 수 있습니다.
