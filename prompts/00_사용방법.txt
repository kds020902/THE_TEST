범용 학습 사이트 제작 패키지
작성일: 2026-10-07

목적
이미 만든 학습 사이트의 흐름을 다른 과목에도 재사용할 수 있도록 제작 요구사항을 정리했습니다.
이 파일들은 ‘새 사이트를 만들 때 사용하는 프롬프트’입니다. 자료를 넣으면 여러 과목을 자동 관리하는 완성 앱이 추가된 것은 아닙니다.

가장 간단한 사용법
1. 02_과목_설정_양식.txt에서 과목명, 강의 자료, 시험 범위를 채웁니다.
2. 새 대화에 01_범용_제작_프롬프트.txt와 채운 양식, 강의 자료를 함께 첨부합니다.
3. 아래처럼 요청합니다.

“첨부한 제작 프롬프트와 과목 설정대로 학습 사이트를 만들어줘.
자료를 읽고 단원별 연습, 모의시험, 오답 복습, 새 문제 생성까지 구현해줘.
03_출제_품질_기준.txt에 따라 검증하고 접속 링크를 줘.”

파일 구성
- 01_범용_제작_프롬프트.txt: 사이트 제작 전체 지시
- 02_과목_설정_양식.txt: 매 과목마다 채울 입력
- 03_출제_품질_기준.txt: 문항과 동작의 검증 기준
- 04_과목별_설정_예시.txt: 평가 방식에 따른 입력 예시
- 05_빠른시작_요청문.txt: 복사해서 쓰는 제작 요청문

GitHub에서 사용하기
이 저장소의 prompts 폴더에 위 파일들이 있습니다. Codex에서 저장소를 열거나 파일을 첨부해 사용합니다.
개인 템플릿 설치는 필수가 아니며, 이 저장소에는 제작 문서만 포함됩니다.
원본 앱 소스가 따로 제공된 경우 해당 소스를 참고해 구현합니다.

입력 범위를 결정하는 방법
- 새 과목 하나: ‘새 과목 사이트’ 선택
- 지금 운영 중인 사이트의 변경: ‘기존 사이트 수정’과 정확한 주소 기재
- 한 사이트에서 여러 과목 선택: ‘여러 과목 통합’ 선택
마지막 방식에는 과목 추가·전환과 과목별 기록 분리가 별도로 필요합니다.

현재 참고 사이트에서 가져온 기능
단원별 연습 / 모의시험 / 오답 복습 / 객관식·단답형·서술형 / 해설과 빠르게 이해하기 / 생성 이력과 답안 저장.

과목에 맞게 다시 만드는 부분
강의 범위, 단원 순서, 개념, 문제와 정답, 이미지, 출처, 채점 규칙, 생성 규칙.
기존의 장 번호와 103개 기본 문제, 945개 생성 조합 수는 새 과목의 고정 기준이 아닙니다.

생성 방식
기본은 검토된 개념과 조건의 조합입니다. 조합 수는 유한합니다.
AI 자유 생성은 별도 선택이며 실제 연결·권한·비용 확인이 필요합니다.
