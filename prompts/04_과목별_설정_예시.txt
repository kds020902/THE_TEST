과목별 설정 예시
아래 범위와 문항 수는 사용법을 보여주는 예시입니다.
실제 수업의 시험 정보를 대신하는 것이 아니며, 원문 강의 자료를 별도로 제공해야 합니다.

예시 1 — 심리학 개념 시험
과목명: 심리학개론
강의 자료: [실제 수업 자료 첨부]
시험 범위: [실제 범위 입력]
평가 대상: 개념 + 짧은 사례
객관식: 12문제
단답형: 12문제
서술형: 2문제
출제 방향: 개념 정의, 유사 이론 구분, 사례에 맞는 개념 선택
단답형: 강의에서 사용하는 한글·영문 용어를 인정
서술형: 두 개념의 공통점·차이점과 사례 적용을 평가
주의: 개념의 적용 조건이 빠진 사례를 정답 하나로 단정하지 않기

예시 2 — 확률과 통계 계산 시험
과목명: 확률과 통계
강의 자료: [실제 수업 자료 첨부]
시험 범위: [실제 범위 입력]
평가 대상: 개념 + 계산
객관식: 10문제
단답형: 10문제
서술형: 2문제
출제 방향: 분포와 전제 조건의 선택, 계산, 결과 해석
단답형: [실제 강의 기준에 따른 소수점 자리·오차 입력]
서술형: 식을 선택한 이유, 중간 논리, 결과의 의미를 평가
주의: 부호·소수점·분모를 제거하는 문자열 정규화 사용하지 않기

예시 3 — 법학 사례형 시험
과목명: [법학 과목명]
강의 자료: [수업 자료와 기준 시점이 명시된 조문·판례 자료]
시험 범위: [실제 범위 입력]
평가 대상: 개념 + 사례
객관식: 10문제
단답형: 10문제
서술형: 2문제
출제 방향: 요건, 예외, 사례에 대한 적용과 논증
서술형: 쟁점 → 관련 원칙·요건 → 사안 적용 → 결론의 근거를 평가
주의: 자료의 기준 시점을 보존하고, 필요한 사실관계가 빠진 사례를 단정하지 않기

예시 4 — 프로그래밍 원리 시험
과목명: [프로그래밍 과목명]
강의 자료: [실제 수업 자료 첨부]
시험 범위: [실제 범위 입력]
평가 대상: 개념 중심, 코드 설명 제외
객관식: 12문제
단답형: 12문제
서술형: 2문제
출제 방향: 원리, 자료구조의 차이, 알고리즘의 적용 조건
주의: API 이름 암기나 코드 실행 결과 문제를 임의로 추가하지 않기
변경 예: 시험이 코드 해석을 포함한다면 언어·버전·입력·실행 가정을 명시하고 채점 규칙을 바꾸기
